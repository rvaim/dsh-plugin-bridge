# 包更名说明

## 新名称

| 项目 | 当前值 |
|---|---|
| 中文名称 | 插件桥 |
| 英文名称 | Plugin Bridge |
| Cordis 插件 ID | `plugin-bridge` |
| npm 包名 | `@rvaim/dsh-plugin-bridge` |
| Host 服务 | `ctx.pluginBridge` |
| RPC 命名空间 | `pluginBridgeAdmin` |
| 侧边栏入口 / 主面板 | `plugin-bridge` |
| Client 文案命名空间 | `pluginBridge` |
| 当前仓库 | `https://github.com/rvaim/dsh-plugin-bridge` |

插件桥用于在 DSH 中安装、管理并运行 Claude Code、Codex 和 Agent Plugins 插件。包级 `locale/zh.json`、`locale/en.json` 导出可供原生插件管理页面读取；独立管理面板使用相同中英文名称。附带的桥形 PNG 图标由本项目原创，随项目 MIT 许可分发。

## 标识范围

Host 插件行、npm 包清单与锁文件、浏览器 ModuleLoader、Typert 生成及类型自引用、服务/RPC 命名空间、设置入口和运行标签使用新标识。类名及统一模型中表示兼容能力的 `Compat*` 名称仍表达其类型职责，不为旧服务或包名提供并行别名。

持久化数据继续存放在 `$DSH_HOME/dsh-compat/`。这是稳定的数据命名空间，改展示名不会自动移动或丢弃既有安装记录。`0.6.0` 的源码上游已迁至 [rvaim/dsh-plugin-bridge](https://github.com/rvaim/dsh-plugin-bridge)，npm repository、homepage 和 issues 链接同步更新；本地检出目录可继续使用原目录名。下文的 `0.5.0` 验证记录保留当时的设置入口和验证范围。

## 验证与状态

`0.6.0` 已完成当前 DSH SDK、Typert、侧边栏管理面板和核心架构优化；完整验收为 270 项测试、8 种解析器组合及 547 个发布文件，见[核心架构优化实施](核心架构优化实施.md)。未在用户 profile 中安装或替换插件，GUI 实际挂载仍需按运维说明安装后验收。

以下保留 `0.5.0` 发布阶段的历史事实。

从 `0.5.0` 起以新 npm 包名交付；版本号与包清单、锁文件和安装示例一致。本轮不安装、替换或卸载当前 profile 中的插件。原生管理页资源和 Client 构建产物已进行静态及发布结构检查；当前 Desktop 的 Typert/Web 迁移仍单独处理，未声称本轮已在现有 GUI 实际挂载显示。

2026-10-21 执行 `npm run verify`：**227/227 测试通过，八种解析器物理移除组合全部通过，509 个发布文件检查通过**。新增测试核对中英文包级 `meta.title` 与设置页标题/导航一致、描述包含三种支持格式，并检查 PNG 格式、尺寸和资源导出。Host/Remote 生成产物、Client ModuleLoader 与设置入口使用新标识。

`0.5.0` 发布前已重新完整执行 `npm run verify`：227 项测试、八种解析器物理移除组合和 509 个发布文件检查全部通过；包与锁文件版本一致。npm 实际可用性以 registry 查询结果为准。

`npm run verify:dsh`、`git diff --check` 与文档本地链接检查通过。DSH 探针仅验证工作区依赖导出，不等同于当前 Desktop 浏览器显示验证。
