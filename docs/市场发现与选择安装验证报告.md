## 3. 发现与路径规则

1. 根市场、根显式插件清单优先；根市场由市场规则处理，根显式插件作为独立插件，不深入其内部寻找市场。
2. 两者都没有时，Claude Code / Codex 签名声明最多深入 4 层寻找固定市场标记；总检查目录上限为 4096。不跟随目录符号链接；遇到市场或显式插件边界即停止向下。
3. 这是插件桥的有界扩展。已取得的 Codex 上游实现检查给定根、个人根和 Git 根，没有建立“任意嵌套目录都自动发现”的递归约定；Claude 在线正文未取得，也不宣称有此规定。
4. 例如 `plugins/claude_code/.claude-plugin/marketplace.json` 的市场根是 `plugins/claude_code/`；`source:"./reme"` 指向 `plugins/claude_code/reme/`。Codex 同样移除 `.agents/plugins/marketplace.json` 后缀确定市场根。Claude 的 `metadata.pluginRoot` 先在市场根内组合。
5. 本地候选按市场根校验后恢复为 Source 仓库根相对路径。内联定义保存完整市场文件路径与 JSON pointer，延迟引用标记 `base:source`；组件声明仍相对插件根。外部 Git 的仓库路径不随本地市场前缀重写。
6. 标记路径必须符合本协议后缀并通过真实路径检查，拒绝逃逸、非文件、断链等错误。本地候选也不得逃出其市场根。
7. 多个市场可共同提供候选，同格式同 ID 的跨市场声明阻断安装，避免静默覆盖策略。只安装市场列出的候选，不递归猜测未列出插件。

## 4. 选择安装与外部来源

| 情形 | 行为 |
|---|---|
| 独立单插件来源 | 保留直接安装 |
| 一个候选的市场 | `selectionRequired:true`，必须明确选择 |
| 多个候选的市场 | 展示候选，只安装明确选中的项 |
| 市场准备 | 固定市场 Source 快照，只读解析候选；不取得候选的外部仓库 |
| 确认选中的外部 Git/git-subdir | 获取外部仓库；`ref` 或默认 HEAD 在确认时解析并记录 commit，`sha` 固定指定提交 |
| 未选中的外部来源 | 不联网、不执行其代码 |
| npm、远端 archive、command | 保留既有未适配诊断，不运行安装或构建脚本；各来源合法性按所属协议判断 |

`revision` 是插件桥 Source 快照的内部修订标识；已核实的上游市场来源使用 `ref` / `sha`。不能据“本地没有读取 revision”推断缺失现行官方 pin 字段。

Claude `strict` 维持既有规则：默认 `true`；有本地清单时，`strict:false` 不允许条目额外声明冲突能力，也不清空本地能力；`strict:true` 的条目同事件 Hook 替换低优先级事件，其余事件保留。本轮没有凭官网 403 后取得的实例重新认定完整 strict 规范，已有行为及回归见[传统插件兼容矩阵](传统插件兼容矩阵.md)。

## 5. 已支持、偏差与缺口

| 分类 | 状态 |
|---|---|
| 已支持 | 两种固定市场路径、本地候选根语义、Claude `metadata.pluginRoot`、Claude `github` / `url` / `git-subdir`、Codex `url` / `git-subdir` / `url.path`、`ref` / `sha`、既有 strict 合并与结构化诊断。 |
| 本轮补齐 | 签名驱动的有界嵌套市场发现、完整市场来源路径、市场无论多少候选都明确选择、候选实际位置与诊断展示；既有外部 Git 按所选项获取并固定提交的行为已补充端到端回归。 |
| 保守偏差 | Codex 上游接受部分相对 Git URL 和短 `sha`；插件桥现有来源 URL 安全子集与 40 位 `sha` 校验更严格，本轮不扩展。 |
| 未纳入本轮 | Codex 上游还认 `.agents/plugins/api_marketplace.json`、`.claude-plugin/marketplace.json`、`.cursor-plugin/marketplace.json`；本地 Codex 模块仍只声明 `.agents/plugins/marketplace.json`，Claude 市场由独立模块处理。 |
| 有诊断的未支持 | npm、远端 archive、command 的安装适配，以及既有不支持的插件能力。 |
| 既有外部更新边界 | `checkUpdates` 目前只探测市场 Source 修订，不能发现市场未变而外部 ref/HEAD 单独前移；显式 `sourceUpdate` 会重新获取已安装外仓。同一外仓的不同候选各自获取，不保证移动 HEAD 共用一次解析结果；需要共同固定版本时可在市场中显式指定 `sha`。本轮不改写更新模型。 |
| 证据限制 | Claude 两页现行在线正文未取得；官方仓库实例与固定旧参考不足以声明完整现行兼容。 |
