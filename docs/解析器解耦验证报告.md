# 解析器解耦验证报告

> 本文保留更名前的验证事实与包名；当前名称为“插件桥 / Plugin Bridge”，npm 包名为 `@rvaim/dsh-plugin-bridge`。包身份调整及其实际验证单独见[包更名说明](<包更名说明.md>)，不以更名重写本文的 226 项历史结果。

## 现状

本轮基于 `@rvaim/dsh-compat` 工作区版本 `0.4.4`，未发布。Plugin/Source 缓存版本为 `5.0.0`，内置解析器实现版本各为 `1.1.0`。协议版本及上游基线保持之前单独记录，不把实现版本当成标准版本。本轮明确不保留旧 API、转发文件或旧运行 IR 兼容分支。

## 目录收敛复验

2026-10-21，源码一级目录已从 13 个收敛为 10 个。加载器移入 `manager`，能力适配器移入 `runtime/adapters`，Host 与浏览器分别归 `web/host`、`web/client`，协议共享描述类型归 `types/protocol.ts`。旧目录删除，没有保留转发壳。

迁移了 12 个文件，43 个文件中的 63 处模块导入按绝对目标重新计算相对路径；非导入业务文本保持一致。浏览器构建入口、Host Typert 分析排除、Client 类型导出及测试文件路径同步更新。模型版本仍为 `5.0.0`，协议实现版本仍为 `1.1.0`。

本次重新执行 `npm run verify`：**226/226 自动化测试通过，八种物理移除组合全部编译和加载成功，505 个发布文件检查通过**。结构守卫固定十个一级目录、Web 前后端边界、扁平的三种运行适配器及中立类型归属。发布检查要求新路径产物，并拒绝旧 `core`、顶层 `adapters`、顶层 `client`、协议 `shared` 和旧 Web gateway 的残留编译文件。本次未安装或改动当前 profile。

## 验证目标

- CC、传统 Codex、Agent Plugins 解析器可独立取消注册并移除实现目录。
- 核心和运行层不导入具体实现，协议模块不互相导入。
- 剩余解析器输出保持一致，缺失格式明确诊断且不被其他默认规则接管。
- 旧缓存、解析器集合/版本变化使 Source/Plugin 重扫；用户数据和 enabled 意愿保留，丢失关键语义的已运行父实例停止。
- 更新事务及回滚、凭据延迟读取、脱敏、Hook 阻断和 Web 生命周期仍按原行为验证。
